# Func Docs

The documentation website for [func](https://github.com/unix/func), a lightweight TypeScript framework for building CLI applications. It covers getting started, core concepts, command APIs, error handling, tooling, and release notes in English and Simplified Chinese.

The site is built with Astro, MDX, and Tailwind CSS, then deployed to Cloudflare Workers as a static site. Visit the published documentation at [func.witt.im](https://func.witt.im).

## Development

Run commands from this directory:

```sh
pnpm dev          # Start the local development server
pnpm test         # Run documentation tests
pnpm format:check # Check formatting
pnpm build        # Create a production build
```
