---
code: F_SYSTEM_INVALID_OPTION_ALIAS
title: 选项 alias 无效
description: 字段选项、OptionCommand 或处理器 flag 中的 alias 不是单字符。
lastModified: '2026-08-08'
---

import CodeBlock from '@/components/content/code-block.astro'

export const reproductionCode = [
  "import { Flag } from 'func'",
  '',
  'class Options {',
  "  @Flag({ aliases: ['v', 'verbose'] })",
  '  verbose = false',
  '}',
].join('\n')

export const fixCode = [
  'class Options {',
  "  @Flag({ aliases: ['v', 'V'] })",
  '  verbose = false',
  '}',
].join('\n')

## 复现

alias 表示短选项，数组中的每一项都必须且只能包含一个字符：

<CodeBlock code={reproductionCode} filename="src/options.ts" lang="ts" />

## 如何修复

让每一项都使用单个字符，或删除无效 alias：

<CodeBlock code={fixCode} filename="src/options.ts" lang="ts" />
