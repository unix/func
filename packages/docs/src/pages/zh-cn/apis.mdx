| API 类别                   | 返回                 | 失败契约                                                |
| -------------------------- | -------------------- | ------------------------------------------------------- |
| 命令与模块装饰器           | `ClassDecorator`     | 无效定义属于 F_SYSTEM 错误，并会阻止分发。              |
| 处理器与 catch 装饰器      | `MethodDecorator`    | 无效目标或互斥参数属于 F_SYSTEM 错误。                  |
| 字段选项装饰器             | `PropertyDecorator`  | 无效定义属于 F_SYSTEM；无效用户值属于 F_RUNTIME_PRINT。 |
| 运行时注入装饰器           | `ParameterDecorator` | 不支持的注入位置属于 F_SYSTEM 错误。                    |
| run(input, options?)       | `Promise<void>`      | 运行时失败会进入局部和全局错误处理流程。                |
| createApp(input, options?) | `Container`          | 容器解析并运行时会验证应用定义。                        |

本页用于查询 API 签名和参数。行为说明和设计建议见 [核心概念](/zh-cn/concepts)、 [字段选项](/zh-cn/options)、[参数注入](/zh-cn/parameters) 和 [错误处理](/zh-cn/error-handler)。

## 命令

| 签名                               | 结构                                                                                                                                                    | 描述                                                                                                 |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `@Command(params: CommandParams)`  | `CommandParams = { path: string \| readonly string[], deprecated?: true \| string, description?: string, alias?: string, aliases?: readonly string[] }` | 注册具名命令。path 或任一 alias 会与输入 token 匹配。                                                |
| `@Handler(params?: HandlerParams)` | `HandlerParams = { flag?: string, alias?: string, aliases?: readonly string[], description?: string, path?: string[] }`                                 | 注册默认、标志或路径处理器。path 不能与 flag 或 aliases 同时使用；选项式 alias 必须为单字符。        |
| `@CommandMissing()`                | `-`                                                                                                                                                     | 注册用于处理未知首个裸输入的 fallback command。它可以像普通命令一样定义 handler 和字段选项。         |
| `@CommandMajor()`                  | `-`                                                                                                                                                     | 注册空调用和顶层选项使用的主命令。                                                                   |
| `onError(exception, context)`      | `Exception, ExceptionContext`                                                                                                                           | 在当前 command、直接 owner module 或根 module 上处理非系统异常。正常返回表示已处理，抛错则继续传播。 |
| `onInit()`                         | `-`                                                                                                                                                     | 初始化已激活的 command、module、option provider 或 provider。                                        |
| `onDispose(outcome)`               | `ExecutionOutcome`                                                                                                                                      | 在成功或失败后清理已激活的受管实例。                                                                 |

## 字段选项和校验器

| 签名                     | 结构                                                                                                                                               | 描述                                                                    |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `@OptionCommand(params)` | `params = { name: string, alias?: string, aliases?: readonly string[], deprecated?: true \| string, description?: string, overrideAll?: boolean }` | 声明 module 作用域的动作选项；每个 alias 必须为单字符。                 |
| `@Flag(params?)`         | `params = { name?: string, alias?: string, aliases?: readonly string[], description?: string, negatable?: boolean }`                               | 声明布尔选项；所有 alias 都是正向形式，`negatable` 注册 `--no-<name>`。 |
| `@Value(params?)`        | `params = { name?: string, alias?: string, aliases?: readonly string[], description?: string }`                                                    | 声明从 design metadata 推断的 `string` 或 `number` 标量选项。           |
| `@ArrayString(params?)`  | `params = { name?: string, alias?: string, aliases?: readonly string[], description?: string }`                                                    | 声明重复字符串选项。                                                    |
| `@ArrayNumber(params?)`  | `params = { name?: string, alias?: string, aliases?: readonly string[], description?: string }`                                                    | 声明重复数字选项。                                                      |
| `@Deprecated(message?)`  | `message?: string`                                                                                                                                 | 将字段选项或 `@Handler({ flag })` 动作标记为废弃；普通成员会被忽略。    |
| `@Required()`            | `-`                                                                                                                                                | 要求选项被显式提供，或已经定义默认值。                                  |
| `@Enum(values)`          | `values = Array<boolean \| string \| number>`                                                                                                      | 校验标量值或数组中的每一项是否位于允许列表中。                          |
| `@DependsOn(options)`    | `options = string[]`                                                                                                                               | 当此选项被显式提供时，要求同时提供其他选项。                            |
| `@Exclusive(options)`    | `options = string[]`                                                                                                                               | 拒绝此选项与列表中的任一选项同时显式出现。                              |
| `@ValueValidate(fn)`     | `fn(value, options) => boolean \| string \| void`                                                                                                  | 运行自定义校验器。返回 false 或字符串会创建校验错误。                   |

## 上下文注入

| 签名      | 描述                                                                              |
| --------- | --------------------------------------------------------------------------------- |
| `@Args()` | 注入 Args：命令元数据、选中的处理器、inputs、path、归一化 option 和原生解析数据。 |
| `@Regs()` | 注入 CommandRegistry，用于读取已注册命令元数据。                                  |

## 应用

| 签名                          | 结构                                                                                                                | 描述                                                           |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `@Module(params)`             | `params = { commands?: Type[], imports?: Array<Type \| ModuleMetadata>, options?: Type[], providers?: Provider[] }` | 创建应用或 feature module；传给 `run` 的根必须是带装饰器的类。 |
| `@Injectable()`               | `-`                                                                                                                 | 标记可注入的类 provider。                                      |
| `run(module, options?)`       | `options = { argv?, cwd?, stdin?, stdout?, stderr?, signal? }`                                                      | 创建并执行应用 module。                                        |
| `createApp(module, options?)` | 与 `run` 相同                                                                                                       | 创建底层 Container，但不执行。                                 |

## 运行时类型

| 签名               | 结构                                                                                   | 描述                                        |
| ------------------ | -------------------------------------------------------------------------------------- | ------------------------------------------- |
| `Args`             | `{ command?, handler?, inputs: string[], native, option: UserOption, path: string[] }` | 由 Args 注入的归一化运行时上下文。          |
| `Exception`        | `code, details, message, scope, cause`                                                 | 传给错误处理器的结构化 `Error` 子类。       |
| `ExceptionContext` | `printPrevented, preventDefaultPrint()`                                                | 与 `Exception` 一同传入的可变错误处理状态。 |
| `CommandRegistry`  | `{ commands: RegisterCommandParams[] }`                                                | 由 Regs 注入的只读注册表上下文。            |
| `Deprecation`      | `true \| string`                                                                       | 废弃标记，以及可选的迁移说明。              |

## 支持命令

`funcgo` 为 `func` 项目提供开发和构建命令。完整用法见 [工具链](/zh-cn/tooling)。

| 签名                        | 结构                                                                                                | 描述                                                                                            |
| --------------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `funcgo setup`              | `--fix?`                                                                                            | 检查 package.json，并建议缺失的 func.entry、func.outDir、bin、dev script 和 build script 配置。 |
| `funcgo dev`                | `-f, --file <entry>; -- <args>`                                                                     | 通过本地 TypeScript 运行时执行项目入口，并把参数透传给命令。                                    |
| `funcgo build`              | `-f, --file <entry>; -o, --out <dir>; -e, --external <package>; -w, --watch; --watch-path <target>` | 打包项目入口、创建可执行 bin.js，并可在文件、目录或正向 glob 变化时重新构建。                   |
| `funcgo --help / --version` | `-h; -v`                                                                                            | 输出 funcgo 命令说明或当前安装版本。                                                            |

## 配置

  <Callout locale="zh-cn" title="setup --fix 会修改 package.json" variant="caution">

已有项目应在修改前检查 `funcgo setup` 的只读输出，尤其要确认通用的 `dev` 或 `build` scripts 没有被宿主应用占用。

  </Callout>

| 签名                       | 描述                                                                          |
| -------------------------- | ----------------------------------------------------------------------------- |
| `package.json#func.entry`  | funcgo dev 和 funcgo build 在未提供 --file 时使用的默认 TypeScript 入口文件。 |
| `package.json#func.outDir` | funcgo build 在未提供 --out 时使用的默认构建输出目录。                        |
| `package.json#bin`         | 把安装后的可执行命令名映射到 func.outDir 中生成的 bin.js。                    |
