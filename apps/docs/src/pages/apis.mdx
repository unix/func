| API family                        | Returns              | Failure contract                                                     |
| --------------------------------- | -------------------- | -------------------------------------------------------------------- |
| Command and module decorators     | `ClassDecorator`     | Invalid definitions are F_SYSTEM errors and stop dispatch.           |
| Handler decorators                | `MethodDecorator`    | Invalid targets or incompatible parameters are F_SYSTEM errors.      |
| Filter and interceptor decorators | `ClassDecorator`     | Invalid providers or scopes are F_SYSTEM errors.                     |
| Field option decorators           | `PropertyDecorator`  | Invalid definitions are F_SYSTEM; invalid user values are F_RUNTIME. |
| Runtime injection decorators      | `ParameterDecorator` | Unsupported injection positions are F_SYSTEM errors.                 |
| createApp(input, options?)        | `App`                | Compiles the module and validates application features.              |
| app.bootstrap(options?)           | `Promise<void>`      | Runs the process entry once and sets `process.exitCode`.             |

Use this page when you already know which func concept you need and want its exact signature. For behavior and design guidance, see [Core Concepts](/concepts), [Field Options](/options), [Parameters](/parameters), and [Error Handling](/error-handler) for behavior details.

## Commands

| Signature                         | Structure                                                                                                                                               | Description                                                                                                                                          |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@Command(params: CommandParams)` | `CommandParams = { path: string \| readonly string[], deprecated?: true \| string, description?: string, alias?: string, aliases?: readonly string[] }` | Register a named command. Its path or any alias is matched against input tokens.                                                                     |
| `@Handler(input?)`                | `'' \| string \| readonly string[] \| { path?, flag?, alias?, aliases?, description? }`                                                                 | Register a default, flag, or path handler. A path cannot be combined with a flag or aliases. Option-style aliases must be one character.             |
| `@CommandMissing()`               | `-`                                                                                                                                                     | Register a fallback command for bare input whose first token is not a known command. It can define handlers and field options like a normal command. |
| `@CommandMajor()`                 | `-`                                                                                                                                                     | Register the major command for empty invocation and top-level options.                                                                               |
| `@UseFilters(...types)`           | `Type<ExceptionFilter>[]`                                                                                                                               | Bind DI-created exception filters to a command. Returning handles the failure; throwing continues propagation.                                       |
| `@UseInterceptors(...types)`      | `Type<Interceptor>[]`                                                                                                                                   | Bind around interceptors to a command.                                                                                                               |
| `onInit()`                        | `-`                                                                                                                                                     | Initialize an activated command, module, option provider, or provider.                                                                               |
| `onDispose()`                     | `void \| Promise<void>`                                                                                                                                 | Release resources owned by an activated managed instance. Failures are absorbed and reported by Runtime.                                             |

## Field Options and Validators

| Signature                         | Structure                                                                                                                                          | Description                                                                                     |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `@OptionCommand(params)`          | `params = { name: string, alias?: string, aliases?: readonly string[], deprecated?: true \| string, description?: string, overrideAll?: boolean }` | Declare a module-scoped action option. Every alias must contain exactly one character.          |
| `@Flag(input?)`                   | `string \| { name?: string, alias?: string, aliases?: readonly string[], description?: string, negatable?: boolean }`                              | Declare a boolean option. Every alias is positive; `negatable` also registers `--no-<name>`.    |
| `@Value(input?)`                  | `string \| { name?: string, alias?: string, aliases?: readonly string[], description?: string }`                                                   | Declare a scalar `string` or `number` option inferred from design metadata.                     |
| `createValueDecorator(transform)` | `(input: string) => Output`                                                                                                                        | Create a custom value decorator that synchronously transforms one string input.                 |
| `@ArrayString(input?)`            | `string \| { name?: string, alias?: string, aliases?: readonly string[], description?: string }`                                                   | Declare a repeated string option.                                                               |
| `@ArrayNumber(input?)`            | `string \| { name?: string, alias?: string, aliases?: readonly string[], description?: string }`                                                   | Declare a repeated number option.                                                               |
| `@Deprecated(message?)`           | `message?: string`                                                                                                                                 | Mark a field option or `@Handler({ flag })` action as deprecated. Ordinary members are ignored. |
| `@Required()`                     | `-`                                                                                                                                                | Require the option to be provided explicitly or have a defined value.                           |
| `@Enum(values)`                   | `values = Array<boolean \| string \| number>`                                                                                                      | Validate that a scalar value, or every array item, is one of the allowed values.                |
| `@DependsOn(options)`             | `options = string[]`                                                                                                                               | Require other options when this option is explicitly provided.                                  |
| `@Exclusive(options)`             | `options = string[]`                                                                                                                               | Reject combinations where this option and one of the listed options are both explicit.          |
| `@ValueValidate(fn)`              | `fn(value, options) => boolean \| string \| void`                                                                                                  | Run a custom validator. Return false or a string to create a validation error.                  |

## Runtime Injection

| Signature   | Description                                                                                               |
| ----------- | --------------------------------------------------------------------------------------------------------- |
| `@Args()`   | Inject the immutable arguments for the selected handler.                                                  |
| `@Ctx()`    | Inject the current runtime `Context`.                                                                     |
| `@Stdin()`  | Inject configured stdin, or `process.stdin` by default, as a Node.js `Readable`.                          |
| `@Stdout()` | Inject configured stdout, or `process.stdout` by default, as a Node.js `Writable`.                        |
| `@Stderr()` | Inject configured stderr, or `process.stderr` by default, as a Node.js `Writable`.                        |
| `@Inject()` | Resolve a class or explicit `InjectionToken` through the current module's dependency-injection container. |

## Application

| Signature                         | Structure                                                                                                           | Description                                                                                        |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `@Module(params)`                 | `params = { commands?: Type[], imports?: Array<Type \| ModuleMetadata>, options?: Type[], providers?: Provider[] }` | Create an application or feature module. The root passed to `createApp` must be a decorated class. |
| `@Injectable()`                   | `-`                                                                                                                 | Mark an injectable class provider.                                                                 |
| `createApp(module, options?)`     | `options = { appName?: string, features?: ApplicationFeature[] }`                                                   | Compile a one-shot process application; filesystem capabilities require `appName`.                 |
| `app.bootstrap(options?)`         | `options = { argv?, cwd?, env?, stdin?, stdout?, stderr?, signal? }`                                                | Run the application once; completion features participate in the same startup lifecycle.           |
| `createInvoker(module, options?)` | `options = { appName?: string }`, imported from `func/invoke`                                                       | Compile a reusable imperative invoker without exposing `bootstrap()`.                              |

## Runtime Types

| Signature         | Structure                                                                              | Description                                                |
| ----------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `Args`            | `{ command?, handler?, inputs: string[], native, option: UserOption, path: string[] }` | Normalized runtime context injected by Args.               |
| `Exception`       | `code, details, message, scope, cause`                                                 | Structured `Error` subclass passed to exception filters.   |
| `ExceptionFilter` | `catch(exception, context)`                                                            | Routes, handles, or returns structured data for a failure. |
| `Interceptor`     | `intercept(context, next)`                                                             | Wraps execution and transforms handler or filter results.  |
| `CommandRegistry` | `{ commands: RegisterCommandParams[] }`                                                | Read-only registry context injected by Regs.               |
| `Deprecation`     | `true \| string`                                                                       | A deprecation marker with an optional migration message.   |

## Support

`funcgo` provides the standard development and build commands for `func` projects. The full workflow is documented in [Tooling](/tooling).

| Signature                   | Structure                                                                                           | Description                                                                                                                   |
| --------------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `funcgo setup`              | `--fix?`                                                                                            | Inspect package.json and suggest missing func.entry, func.outDir, bin, dev script, and build script configuration.            |
| `funcgo dev`                | `-f, --file <entry>; -- <args>`                                                                     | Run the project entry with a local TypeScript runtime and pass arguments through to the command.                              |
| `funcgo build`              | `-f, --file <entry>; -o, --out <dir>; -e, --external <package>; -w, --watch; --watch-path <target>` | Bundle the project entry, create executable bin.js, and optionally rebuild when files, directories, or positive globs change. |
| `funcgo --help / --version` | `-h; -v`                                                                                            | Print funcgo command discovery or the installed funcgo version.                                                               |

## Configuration

  <Callout title="setup --fix changes package.json" variant="caution">

Review the read-only `funcgo setup` output first in existing projects, especially when generic `dev` or `build` scripts already exist.

  </Callout>

| Signature                  | Description                                                                                    |
| -------------------------- | ---------------------------------------------------------------------------------------------- |
| `package.json#func.entry`  | Default TypeScript entry file used by funcgo dev and funcgo build when --file is not provided. |
| `package.json#func.outDir` | Default build output directory used by funcgo build when --out is not provided.                |
| `package.json#bin`         | Map the installed executable name to the generated bin.js inside func.outDir.                  |
