code: F_SCAFFOLD_INVALID_PACKAGE_METADATA
title: Invalid package metadata
description: A package.json file or bundled package record is not a JSON object with the required fields.
lastModified: '2026-08-17'
---

## How to fix it

Validate `package.json`, resolve JSON syntax errors, and ensure required fields such as `name` and `version` are strings. Reinstall the tool if its own bundled metadata is invalid.
