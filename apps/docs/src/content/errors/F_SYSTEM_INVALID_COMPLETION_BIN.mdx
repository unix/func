---
code: F_SYSTEM_INVALID_COMPLETION_BIN
title: Invalid completion binary name
description: Completion setup received an empty or unsafe executable token.
lastModified: '2026-08-17'
---

## How to fix it

Pass the executable token users type, such as `ship`, to `withCompletion({ bin: 'ship' })`. Do not include whitespace or NUL characters.
