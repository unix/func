## 复现

command 字段会遮蔽上层 option provider 的同名字段，但没有显式确认：

<CodeBlock code={reproductionCode} filename="src/app.module.ts" lang="ts" />

## 如何修复

普通重复声明应重命名或删除。确实需要由 command 或 feature `@Option()` 字段替换上层字段时，在该字段上同时使用 `@Override()`；替换根 module 的 `@OptionCommand` 时，在 feature action 上设置 `overrideAll: true`。

覆盖只改变公开 token 的绑定目标，不会把用户值同时写入被遮蔽的上层字段。
