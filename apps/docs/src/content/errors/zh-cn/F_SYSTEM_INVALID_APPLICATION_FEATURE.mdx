## 这个错误是什么

`createApp({ features })` 只接受 `func` 可识别的 `ApplicationFeature`。普通对象、Module、Provider 或通过类型断言伪装成 `ApplicationFeature` 的值没有内部 Feature 定义，因此无法参与 bootstrap。无效值位于 `details.feature`。

## 如何修复

使用对应可选入口公开的 factory，例如 `withCompletion({ bin: 'ship' })` 或 `withProcessSignals()`。Module 应放入 `Module.imports`，Provider 应放入 `Module.providers`；不要手写或复制 Feature 对象。
