## 这个错误是什么

`completionSource(bin, shell)` 只能为 `bash`、`elvish`、`fish`、`nushell`、`powershell` 或 `zsh` 生成适配器。通过 JavaScript、配置文件或类型断言传入其他值时会抛出此错误，原始值位于 `details.shell`。

## 如何修复

把 shell 名称归一化为受支持的小写值，并在自定义集成中拒绝未知输入。Windows 的有效值是 `powershell`，不是 `pwsh` 或 `cmd`。使用标准安装流程时，应直接采用 [Shell 补全](/zh-cn/extensions/completion)提供的命令。
