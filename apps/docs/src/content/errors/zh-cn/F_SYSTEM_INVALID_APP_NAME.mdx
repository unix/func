---

## 这个错误是什么

需要应用目录的能力会把 `appName` 用于用户主目录下的路径，例如 `appName: 'ship'` 对应 `~/.ship`。为避免路径逃逸，名称必须是非空字符串，并满足：

- 开头和结尾没有空白；
- 不是 `.` 或 `..`；
- 不包含 `/`、`\\` 或 NUL 字符。

无效值位于 `details.appName`。仅使用内存能力时，`createApp` 可以透传任意名称；该错误会在 Config、Log 等真正解析应用目录时产生。

## 如何修复

在 `createApp(AppModule, { appName: 'ship' })` 中使用稳定、安全的应用标识。不要传入路径、用户输入或带目录分隔符的 package scope；如果需要自定义存储位置，应由对应能力提供专门的路径配置。
