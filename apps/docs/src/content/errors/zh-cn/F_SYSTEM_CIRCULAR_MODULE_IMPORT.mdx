## 如何修复

根据 `details.dependencyPath` 找到回到起点的 import。把共享 Provider 提取到第三个 Module，由原来的两个 Module 单向 import；不要让 feature Modules 互相 import。仅需要类型时使用 type-only import，不要把它加入 `Module.imports`。
