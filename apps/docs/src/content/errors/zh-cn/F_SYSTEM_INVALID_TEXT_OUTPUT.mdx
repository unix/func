## 复现

`textOutput` 不接受 `stderr` 或其他自定义通道：

<CodeBlock code={reproductionCode} filename="src/report.option.ts" lang="ts" />

## 这个错误是什么

`textOutput` 告诉结果 Interceptor 普通文本已经由哪个通道负责：

- `return`：使用 handler return，省略时也是该行为；
- `stdout`：handler 已自行写入 stdout，不再重复输出 return。

其他字符串没有明确语义，原始值位于 `details.textOutput`。

## 如何修复

删除 `textOutput`、设为 `return`，或在 action 确实自行渲染普通文本时设为 `stdout`。stderr 是诊断通道，不应作为正常结果策略。
