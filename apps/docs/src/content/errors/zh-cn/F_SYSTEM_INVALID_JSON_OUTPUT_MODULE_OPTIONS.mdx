## 复现

<CodeBlock code={reproductionCode} filename="src/app.module.ts" lang="ts" />

## 如何修复

使用 `JsonOutputModule` 接受默认值，或调用 `JsonOutputModule.register({ suppressStdout: false })`。`register()` 的参数必须是对象，`suppressStdout` 省略时默认为 `true`。无效配置或字段值位于 `details.value`。完整行为见 [JSON 输出](/zh-cn/capabilities/json-output)。
