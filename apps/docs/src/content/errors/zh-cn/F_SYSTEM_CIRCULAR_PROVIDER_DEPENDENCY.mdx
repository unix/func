## 这个错误是什么

class 构造函数或 factory `inject` 形成闭环，例如 A 依赖 B、B 又依赖 A。`func` 不会创建只初始化一部分的实例，因此停止解析并把完整闭环写入 `details.dependencyPath`。

## 如何修复

优先重新划分职责，让一个 Provider 只依赖更底层的接口。也可以把双方共同需要的状态提取到第三个 Provider，或把其中一个同步构造依赖改成 Handler 显式传入的数据。不要通过全局变量或构造后手动回填实例隐藏循环。
